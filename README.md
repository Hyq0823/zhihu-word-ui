# 知乎摸鱼助手

把知乎的专栏文章 / 回答 / 问题页,重新以**腾讯文档风格**的外壳渲染,
让你在摸鱼的时候看起来像在正经看文档 📄。

零依赖、零构建,纯 JS + CSS,直接加载即可。

## 功能

- 📄 **腾讯文档风格外壳**:顶栏 + 标签栏 + 单行工具栏 + A4 纸张
- 🏷️ **浏览器级伪装(v0.8)**:tab 标题变为「{文件名}.docx - 腾讯文档」、favicon 换成文档图标,Chrome 历史记录同步不留知乎痕迹;退出伪装完整还原
- 🚨 **老板键(v0.8)**:双击 `Esc` 全屏盖上"无害画面"(假终端构建日志 / 假 Excel 报表 / 跳转预置工作页),同时进入浏览器全屏连 tab 条一起遮住;再按一次 `Esc` 退出全屏并恢复,页面与伪装状态原样不动
- ↩ **应急可回场(v0.8.1)**:跳转工作页模式自动记下阅读现场,扩展弹窗出现"返回阅读"按钮,一键回到刚才那篇文档(历史记录被伪装,不用再找)
- 💬 **回复弹层收编(v0.8.2)**:评论"回复"弹出的"75条回复"卡片不再被顶栏裁头、不再压深黑遮罩,统一收敛为"批注回复卡片"样式(限高内滚、吸顶标题、编辑器同款浅灰底)
- ⚙️ **自动伪装策略(v0.8)**:详情页自动(默认)/ 全站自动 / 完全手动 / 停用,四档可选;「完全手动」下详情页也能永久关闭伪装
- ⚡ **零频闪**:document_start 同步判定并注入,第一帧即是文档界面,知乎原生 UI 全程不可见
- 🎯 **精准页面识别**:自动匹配 `/p/xxx`、`/column/xxx`、`/question/xxx`、`/question/xxx/answer/xxx`、`/answer/xxx`、`/people/xxx`
- 🗑️ **隐藏干扰元素**:AppHeader / Sidebar / Footer / 广告等统统干掉;评论区默认隐藏,可在弹窗开启
- 💬 **评论区批注样式(v0.8)**:弹窗打开「伪装时显示评论区」后,首页/问答页/文章页出现评论入口(灰色小字 chip),评论列表伪装成"文档批注面板"(左竖线+浅灰底+小字);展开/回复/点赞/翻页全部保持知乎原生交互
-  **正文视频屏蔽(v0.8)**:与图片同机制——默认显示【视频 N · 移入查看 / 点击固定】占位符,悬停或点击固定后露出原生播放器(控件不拦截)
- 🔀 **SPA 路由监听**:history.pushState / replaceState + popstate 全覆盖,路由切换 0 延迟同步换模式
- 👀 **懒加载监听**:MutationObserver + 300ms debounce,知乎 DOM 更新了自动刷新顶栏文件名与 tab 标题
- ⌨️ **可配置快捷键**:默认双击空格切换伪装,可改 Alt+Q / Ctrl+Alt+D / 关闭;输入框内不触发
- 🫥 **FAB 隐匿(v0.8)**:伪装态右下角悬浮按钮默认不可见(腾讯文档里没有它),鼠标悬停右下角浮现;可在弹窗设置常显
- 🖱️ **不阻断原生交互**:链接、滚动、无限加载、收起/展开均保持知乎原生行为(赞同/分享等操作按钮隐藏;评论区可按开关显示)
- 🧭 **回答者导航(v0.8.3 增强)**:问题页左栏按序号列出"1. 回答者 · 赞同数"(回答内标题为子项),滚动同步高亮当前在读回答,点击快速跳转;目录上方实时显示**阅读进度**「回答 3/1237 · 0.2%」(总数取自"1,237 个回答"标题,读不到则按已加载数)
- 🧩 **调试接口**:控制台 `window.__tdoc` 可直接 `toggle()` / `panic()` / `diag()` 等

## 安装

### 方式一:直接加载已解压扩展

1. 下载本仓库,把 `ext-standalone/` 整个目录解压到本地某个位置(不要删里面的文件)。
2. Chrome 地址栏输入:

   ```
   chrome://extensions/
   ```

3. 右上角打开 **开发者模式**。
4. 点击 **加载已解压的扩展程序**,选择刚才那个 `ext-standalone` 文件夹。
5. 扩展列表里会出现一个"知乎摸鱼助手" ✅。

> Edge、Brave、Arc 等 Chromium 内核浏览器同理。

## 使用

1. 打开任意知乎专栏文章、回答或问题页,比如:
   - `https://zhuanlan.zhihu.com/p/123456789`
   - `https://www.zhihu.com/question/123456789/answer/987654321`
2. 页面会**自动**套上腾讯文档风格的外壳(首页默认不伪装),tab 标题与图标同步变为腾讯文档。
3. 切换伪装的方式任选其一:
   - **双击空格**(默认快捷键,可在弹窗中改为 Alt+Q / Ctrl+Alt+D / 关闭)
   - 鼠标悬停页面右下角,点击浮现的 📄 悬浮按钮(伪装态默认隐匿)
   - 点击工具栏扩展图标 → 开启/关闭文档伪装
4. **老板来了**:双击 `Esc`,屏幕瞬间变成滚动的编译日志并进入全屏(连浏览器 tab 条一起遮住);老板走了按一次 `Esc`(退出全屏即恢复)或再双击恢复。覆盖画面(假终端/假表格/跳转工作页)在弹窗中配置;跳转工作页后可在扩展弹窗点"返回阅读"一键回到刚才那篇。
5. 快捷键在输入框(评论/回答/搜索)内不会触发,不影响正常输入;老板键则任何时候都生效(应急不问上下文)。

## 配置(工具栏弹窗)

| 配置项 | 选项 | 说明 |
|---|---|---|
| 自动伪装 | 详情页自动(默认)/ 全站自动 / 完全手动 / 停用 | 「完全手动」下详情页也不强制伪装,手动开关持久生效;「停用」= 从不自动伪装 |
| 切换快捷键 | 双击空格 / Alt+Q / Ctrl+Alt+D / 关闭 | 伪装开关 |
| 伪装时显示悬浮按钮 | 勾选框 | 默认关(隐匿);找不到右下角热区时可打开 |
| 伪装时显示评论区 | 勾选框 | 默认关(评论入口与列表全隐藏);打开后评论以"文档批注"样式显示,交互保持原生 |
| 老板键触发 | 双击 Esc / 关闭 | 应急覆盖 |
| 覆盖画面 | 假终端 / 假表格 / 跳转工作页 | 跳转模式需填写 `https://` 开头的地址 |

所有配置经 `chrome.storage.sync` 跨设备同步;自动伪装策略另有 localStorage 镜像,保证首帧零频闪。

## 调试

F12 打开控制台后:

```js
__tdoc.getState()          // 当前状态(disguised / panic / lastUrl)
__tdoc.getConfig()         // 当前配置(策略/快捷键/老板键)
__tdoc.toggle()            // 切换外壳显隐
__tdoc.show() / __tdoc.hide()
__tdoc.panic()             // 触发/收起老板键覆盖层
__tdoc.panicHide()         // 强制收起覆盖层
__tdoc.setStrategy('manual') // 切换自动伪装策略
__tdoc.pageType()          // 当前页面类型判定
__tdoc.diag()              // 采集页面 DOM 结构(含评论区结构 dump),报障时贴上
```
